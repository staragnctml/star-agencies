# Star Agencies Online Catalogue
A free static product catalogue for GitHub Pages.

## Run on Windows
1. Open this folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click `index.html` -> Open with Live Server.

## Add products
Edit `data/products.json`.
Put product photos inside `images/products/`.
Example:
{
  "id": 4,
  "name": "Product Name",
  "category": "Plastic",
  "brand": "Brand Name",
  "price": "350",
  "image": "images/products/my-photo.jpg",
  "description": "Product description",
  "stock": "In Stock"
}

WhatsApp number is currently set to +91 9447016013 in `js/products.js` and `contact.html`.
